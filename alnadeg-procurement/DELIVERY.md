# تقرير التسليم

## ⚠️ أولاً: ما لم يُنفَّذ ولماذا — اقرأ هذا قبل أي شيء

بُني هذا العمل داخل حاوية تنفيذ معزولة. **الشبكة الصادرة محجوبة** نحو:

- `wdtylpgeyjuetarwtbev.supabase.co` → رد البوابة `403 CONNECT`
- `branch-procurement-portal.m-baomar.chatgpt.site` → رد البوابة `403 CONNECT`

كما أن مفاتيح Supabase غير متاحة في هذه البيئة — وهذا صحيح أمنيًا، لأن
`SERVICE_ROLE_KEY` يجب ألا يمر عبر أي وسيط.

### النتيجة المباشرة

| المطلوب | الحالة | السبب |
|---|---|---|
| رابط برنامج منشور يعمل | ❌ لم يُنفَّذ | لا يمكن النشر من بيئة محجوبة |
| رابط تفعيل مدير النظام | ❌ لم يُنفَّذ | يتطلب كتابة رمز في قاعدتك الحيّة |
| تطبيق الهجرات على قاعدتك | ❌ لم يُنفَّذ | القاعدة غير قابلة للوصول |
| فحص المخطط الفعلي القائم | ❌ لم يُنفَّذ | القاعدة غير قابلة للوصول |
| تشغيل اختبارات القبول حيًّا | ❌ لم يُنفَّذ | تتطلب بيئة منشورة |
| Security Advisor | ❌ لم يُنفَّذ | يتطلب لوحة تحكم المشروع |

**أي رابط أو نتيجة اختبار حيّ يُقدَّم هنا سيكون ملفّقًا.** لذلك لم يُقدَّم.

### ما نُفِّذ فعليًا بدلاً من ذلك

كل الكود مكتوب ومُختبَر على **PostgreSQL 16 حقيقي** شُغِّل محليًا مع
محاكاة كاملة لبيئة Supabase (أدوار `anon`/`authenticated`/`service_role`،
سكيما `auth` و`storage`، ونفس الصلاحيات الافتراضية). النتائج أدناه
قياسات فعلية لا ادّعاءات.

النشر أصبح **أوامر موثّقة تنفّذها بمفاتيحك** خلال ٢٠–٣٠ دقيقة (القسم 5
من README)، ثم `npm run acceptance` يُخرج نتائج اختبارات القبول الـ25.

`documents/sign-download`, `reports/export`).

## 8. خطواتك التالية

```bash
cd alnadeg-procurement
npm install

# 1) افحص قاعدتك القائمة أولاً
DATABASE_URL="postgresql://postgres:<pw>@db.wdtylpgeyjuetarwtbev.supabase.co:5432/postgres" \
  ./scripts/inspect-schema.sh > schema-before.txt

# 2) طبّق الهجرات (تراكمية — لا تحذف شيئًا)
npx supabase link --project-ref wdtylpgeyjuetarwtbev
npx supabase db push

# 3) انشر الدالة
npx supabase secrets set ALLOWED_ORIGINS="https://<your-app>.vercel.app"
npx supabase functions deploy procurement-portal --no-verify-jwt

# 4) انشر الواجهة
npm run build && npx vercel --prod

# 5) ولّد رابط التفعيل الحقيقي
SUPABASE_URL=… SUPABASE_SERVICE_ROLE_KEY=… APP_BASE_URL=… \
  node scripts/create-activation-link.mjs --phone 0559847714

# 6) شغّل اختبارات القبول
npm run acceptance
```

**الخطوة 1 مهمة:** قاعدتك تحتوي جداول قائمة بمخطط لم أتمكن من رؤيته.
الهجرات مكتوبة دفاعيًا (`ADD COLUMN IF NOT EXISTS` ولا `DROP` إطلاقًا)،
لكن إن كان عمود قائم بنوع مختلف (مثل `role` كـ ENUM بدل `text`)، سيظهر
ذلك في تقرير الفحص ويحتاج مواءمة يدوية بسيطة قبل الخطوة 2.
