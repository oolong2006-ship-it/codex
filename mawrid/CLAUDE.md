# مَورِد (Mawrid) — دليل موردي الهوريكا في السعودية

## الهدف
منصة تجمع موردي قطاع الهوريكا (فنادق، مطاعم، كافيهات، تموين) في المملكة بكل تفاصيلهم النظامية والتجارية،
ليبحث المشتري ويقارن ويتواصل. الهدف الأول: 1000 مورد حقيقي في الإصدار الأول.

مالك المنتج: محمد باعمر — مدير المشتريات وصيانة الفروع، مطاعم الناضج (الرياض).
أسلوب العمل: تسليمات جاهزة للتشغيل، تكرار سريع، تواصل بالعربي.

## الوضع الحالي
- `prototype/horeca-suppliers.html`: نموذج أولي يعمل (MVP) بصفحة HTML واحدة — بحث، فلترة، ملف المورد، إضافة/تعديل،
  مقارنة 3 موردين، تصدير CSV، استيراد جماعي من Excel/CSV مع منع التكرار. يُستخدم كمرجع للواجهة والحقول فقط.

## التقنية المعتمدة للإصدار الإنتاجي
- Next.js (App Router) + TypeScript + Tailwind، واجهة RTL عربية أولاً، خط IBM Plex Sans Arabic.
- Supabase: Postgres + Auth + Storage (مستندات الموردين). الانتقال لاستضافة داخل المملكة لاحقاً (نظام حماية البيانات الشخصية PDPL).
- بحث عربي: Postgres full-text + تطبيع (أ/إ/آ→ا، ة→ه، ى→ي، حذف التشكيل والتطويل).
- الاستيراد: SheetJS، مع مطابقة أعمدة عربية/إنجليزية.

## خارطة الطريق
1. **السبرنت 1:** نقل النموذج الأولي إلى Next.js + Supabase مع نفس الميزات، تسجيل دخول لفريق المشتريات، صلاحيات (مدير/مدخل بيانات/مشاهد).
2. **السبرنت 2:** الاستيراد الجماعي بمعاينة وتقرير أخطاء لكل صف، وسجل مصدر البيانات، وتحميل قائمة موردي الناضج.
3. **السبرنت 3:** بوابة التسجيل الذاتي للموردين مع رفع المستندات (السجل، الشهادة الضريبية، التراخيص)، وسير اعتماد.
4. **السبرنت 4:** مساعد مشتريات ذكي (بحث بلغة طبيعية)، وتكامل التحقق من السجل التجاري (واثق) عند توفر اشتراك.

## قواعد لا تُكسر
- لا تُدخل بيانات مورد مخترعة. أي بيانات غير مؤكدة حالتها «قيد التحقق» مع ذكر مصدرها.
- لا تخزن بيانات خرائط Google (Places) في قاعدة البيانات — شروط Google تمنع ذلك.
- البيانات التجريبية تحمل `demo = true` ويمكن حذفها بأمر واحد.
- الواجهة عربية RTL بالكامل، ومتجاوبة مع الجوال أولاً.
