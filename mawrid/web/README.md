# مَورِد — الإصدار الإنتاجي (السبرنت 1)

دليل موردي الهوريكا في المملكة: بحث عربي، فلترة، ملف المورد، إضافة وتعديل، مقارنة حتى 3 موردين،
تصدير Excel، واستيراد جماعي مع منع التكرار. الدخول لفريق المشتريات فقط، بثلاث صلاحيات.

| الطبقة | التقنية |
|---|---|
| الواجهة | Next.js 15 (App Router) + TypeScript + Tailwind، RTL، خط IBM Plex Sans Arabic، وضع داكن تلقائي |
| البيانات والدخول | Supabase (Postgres + Auth) — كل الحماية في سياسات RLS |
| البحث | تطبيع عربي داخل Postgres (`app.normalize_ar`) + فهرس trigram |
| الاستيراد والتصدير | SheetJS (يُحمَّل عند الحاجة فقط) |
| النشر | تصدير ثابت `out/` — يعمل على Vercel أو Netlify أو GitHub Pages أو أي استضافة ملفات |

## الصلاحيات

| | مشاهد | مدخل بيانات | مدير |
|---|:-:|:-:|:-:|
| بحث، عرض، مقارنة، تصدير | ✅ | ✅ | ✅ |
| إضافة، تعديل، استيراد | | ✅ | ✅ |
| حذف مورد، حذف كل التجريبي | | | ✅ |
| إدارة المستخدمين (الدور والتفعيل) | | | ✅ |

الحساب الجديد يبدأ **مشاهداً موقوفاً** حتى يفعّله المدير. الزائر غير المسجّل لا يرى شيئاً.

## التشغيل لأول مرة (مرة واحدة)

1. **أنشئ مشروع Supabase** (يفضَّل منطقة قريبة؛ الانتقال لاستضافة داخل المملكة لاحقاً لأجل PDPL).
2. **طبّق قاعدة البيانات:** من SQL Editor نفّذ الملفات الثلاثة بالترتيب:
   `supabase/migrations/20260923120000_core_schema.sql` ثم `…120100_functions.sql` ثم `…120200_rls.sql`.
   (أو `supabase db push` إن كنت تستخدم Supabase CLI.) الملفات آمنة لإعادة التنفيذ.
3. **أغلق التسجيل الذاتي:** Authentication → Sign In / Providers → Email →
   أوقف **Allow new users to sign up**. (حتى لو نُسي فالحساب الجديد موقوف، لكن الإغلاق أنظف.)
4. **اضبط روابط الدخول:** Authentication → URL Configuration → Site URL = رابط الموقع،
   وأضف `https://رابط-الموقع/reset-password/` إلى Redirect URLs (لرسائل الدعوة واستعادة كلمة المرور).
5. **أنشئ حسابك:** Authentication → Users → Add user → Create new user (مع Auto Confirm).
6. **اجعل نفسك مديراً:** افتح `supabase/tools/make-admin.sql`، ضع بريدك، ونفّذه في SQL Editor.
7. **شغّل الواجهة:** انسخ `.env.example` إلى `.env.local` وضع `NEXT_PUBLIC_SUPABASE_URL`
   ومفتاح **anon** (وليس service_role)، ثم:

```bash
npm ci
npm run dev        # http://localhost:3000
npm run build      # يُخرج الموقع الثابت في out/
```

### إضافة أعضاء الفريق
Supabase → Authentication → Users → Add user → **Send invitation** (يصله بريد لتعيين كلمة المرور)،
ثم من صفحة **المستخدمون** داخل مَورِد: اضغط «تفعيل» واختر الدور.

### النشر
المخرج `out/` ملفات ثابتة. على Vercel/Netlify: أمر البناء `npm run build` ومجلد النشر `out`
مع متغيري البيئة أعلاه. تحت مسار فرعي (مثل GitHub Pages `/codex`) اضبط أيضاً `NEXT_PUBLIC_BASE_PATH=/codex`.

## الاختبارات

```bash
npm run typecheck
npm test           # تطبيع عربي، تحقق المدخلات، مطابقة أعمدة الاستيراد ومنع التكرار
npm run db:test    # PostgreSQL 16 محلي: الصلاحيات (RLS)، البحث، القيود، منع التكرار
npm run verify     # الأنواع + الوحدة + البناء
```

سير العمل `.github/workflows/mawrid-ci.yml` يشغّلها كلها تلقائياً عند أي تعديل على `mawrid/web`.

## قرارات تصميم مهمة

- **منع التكرار:** عمود محسوب `dedup_key` = السجل التجاري إن وُجد، وإلا الاسم+المدينة بعد التطبيع.
  الاستيراد يعمل `upsert` عليه: المورد الموجود يُحدَّث ولا يُكرَّر. ويبقى `cr` فريداً أيضاً.
- **لا بيانات بلا مصدر:** `source` إلزامي لكل مورد غير تجريبي (قيد في قاعدة البيانات)، والاستيراد يسجّل
  «قيد التحقق» لأي حالة لم تُكتب «موثّق» صراحة.
- **التطبيع العربي** مكتوب مرتين (SQL و TypeScript) بنفس القواعد، ولكل منهما اختبارات بنفس الحالات.
- **البيانات التجريبية** (`demo = true`) تُحذف بزر واحد للمدير أو بـ `select public.delete_demo_suppliers();`.
  لم تُضف أي بيانات موردين؛ القاعدة تبدأ فارغة.
- **الاستيراد ما زال كما في النموذج الأولي مع تحسينات:** تقرير أخطاء لكل صف برقم صفه في Excel، وتحذير من
  التصنيفات أو المدن غير المعروفة بدل حذفها بصمت. المعاينة التفصيلية وسجل المصدر هي عمل السبرنت 2.

## ملاحظة أمنية: SheetJS
حزمة `xlsx@0.18.5` على npm عليها تنبيهان معروفان (Prototype Pollution و ReDoS) عند قراءة ملف خبيث.
الخطر هنا محدود: القراءة تتم في متصفح مستخدم مسجّل لملف اختاره بنفسه، ولا خادم يعالج الملفات.
الإصدار المصحح يُوزَّع من SheetJS مباشرة وليس من npm، فالترقية عند توفر الشبكة:

```bash
npm i https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz
```
