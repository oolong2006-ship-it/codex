# باحث الوظائف الشخصي (job-hunter)

برنامج يبحث لك يومياً عن الوظائف المناسبة في السعودية، ويقيّم كل وظيفة مقابل سيرتك الذاتية، ويرسل لك الأنسب على تيليجرام. ويجهّز لك عند الطلب سيرة مخصصة وخطاب تقديم لأي وظيفة.

> **الخصوصية:** هذا المستودع عام. لا تضع سيرتك أو أي مفتاح داخل الملفات. البيانات الشخصية تُحفظ في **أسرار GitHub** أو في ملف `profile.json` المحلي (مستثنى من git).

## كيف يعمل

1. **البحث:** يجمع الوظائف من:
   - **Google Jobs** عبر SerpAPI. يغطي LinkedIn وBayt وIndeed وGulfTalent ومواقع الشركات (يحتاج `SERPAPI_KEY`).
   - **Jooble** (يحتاج `JOOBLE_KEY`، اختياري).
   - **لوحات Greenhouse وLever** لشركات محددة تضيفها في الملف المهني (بدون مفتاح).
2. **فلترة سريعة مجانية:** تعتمد على الكلمات المفتاحية في المسمى والمهارات والمدينة، وتستبعد المستويات غير المناسبة (متدرب، مساعد...). تفهم العربية: "المشتريات" تطابق "مشتريات".
3. **تقييم بالذكاء الاصطناعي** (Claude، اختياري، يحتاج `ANTHROPIC_API_KEY`): نسبة توافق مع سبب مختصر والفجوات بالعربي.
4. **إزالة التكرار:** الوظيفة نفسها المنشورة في أكثر من موقع تظهر مرة واحدة، ولا تُرسل لك الوظيفة مرتين.
5. **إرسال الأفضل على تيليجرام** مع رابط التقديم ورمز الوظيفة.

البرنامج **لا يضغط "تقديم" نيابة عنك**. التقديم الآلي يخالف شروط LinkedIn وBayt وغيرها وقد يُحظر حسابك. هو يجهّز كل شيء، وأنت تقدّم بضغطة.

## الأوامر

```bash
pip install -r requirements.txt
cp profile.example.json profile.json   # ثم عدّله

python -m jobhunter run --no-notify     # ابحث واعرض النتائج هنا بدون إرسال
python -m jobhunter run                 # ابحث وأرسل على تيليجرام
python -m jobhunter list                # الوظائف المحفوظة
python -m jobhunter set <رمز> applied   # سجّل أنك قدّمت (applied/interview/offer/rejected/skipped)
python -m jobhunter pack <رمز>          # سيرة مخصصة + خطاب تقديم عربي وإنجليزي + أسئلة مقابلة
python -m jobhunter report              # تقرير HTML في data/report.html
```

قاعدة ملف التقديم (`pack`): **لا يخترع أي خبرة أو رقم أو شهادة**. يعيد صياغة ما في سيرتك فقط، ويذكر ما ينقصك في قسم "فجوات".

## التشغيل اليومي التلقائي (GitHub Actions)

الملف `.github/workflows/daily-digest.yml` يشغّل البحث يومياً الساعة 7:17 صباحاً بتوقيت الرياض. أضف هذه الأسرار من Settings ← Secrets and variables ← Actions:

| السر | إلزامي؟ | من أين |
|---|---|---|
| `JOBHUNTER_PROFILE_JSON` | ✅ | محتوى ملف `profile.json` كاملاً |
| `SERPAPI_KEY` | ✅ (المصدر الرئيسي) | serpapi.com، الخطة المجانية تكفي لعدد محدود من عمليات البحث شهرياً |
| `TELEGRAM_BOT_TOKEN` | ✅ | أنشئ بوت من @BotFather |
| `TELEGRAM_CHAT_ID` | ✅ | أرسل رسالة لبوتك ثم افتح `https://api.telegram.org/bot<TOKEN>/getUpdates` وخذ `chat.id` |
| `ANTHROPIC_API_KEY` | اختياري | console.anthropic.com، لتقييم أدق وملفات التقديم |
| `JOOBLE_KEY` | اختياري | jooble.org/api/about |

ملاحظات:
- الجدولة في GitHub تعمل فقط من الفرع الافتراضي للمستودع. ويمكن التشغيل يدوياً من تبويب Actions (Run workflow).
- سجل التشغيل يطبع أعداداً فقط بدون أسماء وظائف أو بيانات شخصية. لا يُرفع أي ملف، ويُحفظ متتبع الوظائف في ذاكرة Actions المؤقتة.
- عدد عمليات البحث = عدد `queries` × عدد `locations` يومياً. قلّلها إذا كانت خطة SerpAPI محدودة.
