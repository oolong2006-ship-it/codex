# BUSINESS_MODEL — الشرائح والباقات واقتصاديات الوحدة

> لا أسعار مخترعة. الأرقام النهائية قرار المؤسس (D-04). أدناه الهيكل ونموذج الحساب.

## الباقات
| الباقة | المحتوى | سقوف مقترحة |
|---|---|---|
| Free Diagnostic | تسجيل، مقابلة، هيكل النظام (Blueprint) مقروء | بلا توليد وثائق؛ لا يُعد تدقيقاً |
| System Build | توليد الوثائق، التحرير، الاعتماد، DOCX/PDF/ZIP | عدد مواقع، عدد إعادة توليد، اقتراحات AI/شهر |
| Build + Expert Review | ما سبق + مراجعة خبير بشري مخوّل فعلياً | ساعات مراجعة محددة |
| Operate Subscription | التشغيل الرقمي (CAPA، تدقيق، KPI، موردون، تدريب) سنوياً | مستخدمون، مواقع، تخزين |
| Enterprise / IMS | مواصفات متعددة، مواقع كثيرة، SSO، اتفاقية مستوى خدمة | تعاقدي |

## نموذج تكلفة الوحدة (لكل مشروع System Build)
```
COGS = تكلفة AI + المراجعة البشرية + الحوسبة والتخزين + رسوم الدفع + الدعم + احتياطي الاسترداد
```
- **تكلفة AI الحالية = 0** للمسار الأساسي (المحرك الحتمي rules:v1). الاقتراحات الاختيارية تُقاس فعلياً في `model_runs` (مثال الاختبار: 1000 رمز إدخال + 500 إخراج على claude-opus-5-5 = 0.014$).
- سقف تكلفة AI شهري لكل مستأجر قابل للضبط (`AI_MONTHLY_BUDGET_USD`) ومفروض في الكود.
- الحوسبة: Postgres مُدار + خادم ويب + عامل؛ تُقاس بعد اختيار الاستضافة (D-02).

## ما يلزم لاعتماد الأسعار
1. تكلفة الاستضافة الشهرية الفعلية (بعد D-02).
2. أجر ساعة المراجع البشري وعدد الساعات لكل باقة.
3. رسوم مزود الدفع (D-03).
4. أسعار المنافسين المحليين (بحث سوق — يمكن تنفيذه عند الطلب).
