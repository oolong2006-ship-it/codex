## كيف تستأنف
```bash
cd iso-platform && npm ci
PGSUPER_URL=postgresql://postgres:postgres@localhost:5432/postgres bash scripts/db-setup.sh
cp .env.example .env && set -a && . ./.env && set +a
npm run db:migrate && npm test && npm run build && npm start   # http://localhost:3100
npm run worker   # عامل المهام (اختياري محلياً)
```
