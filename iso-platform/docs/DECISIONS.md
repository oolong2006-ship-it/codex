# DECISIONS — ADR والافتراضات وقرارات المؤسس

## سجل القرارات المعمارية (ADR)
| ADR | القرار | السبب | البدائل المرفوضة |
|---|---|---|---|
| 001 | Next.js 16 + React 19 + TypeScript strict | SSR/RTL/i18n، Server Actions تقلل سطح API، 0 ثغرات في `npm audit` (15.x كان فيه ثغرات) | Next 15.1 (ثغرات معروفة) |
| 002 | PostgreSQL + SQL migrations صريحة + `pg` | RLS ومحفزات وصلاحيات مراجَعة صراحة | Prisma (محركات ثنائية + RLS أصعب) |
| 003 | عزل بالـRLS ودور تطبيق بلا BYPASSRLS | دفاع في العمق: خطأ في الكود لا يسرّب بيانات مستأجر آخر | tenant_id في الكود فقط |
| 004 | طابور مهام في Postgres (SKIP LOCKED) + عامل مستقل | لا بنية إضافية؛ دائم؛ قابل للاستئناف | serverless فقط؛ Redis/BullMQ مبكراً |
| 005 | محرك حتمي rules:v1 للمحتوى الأساسي، وAI مساعد اختياري بمدقق مستقل | لا اختلاق، تكلفة صفرية، قابلية اختبار | توليد كامل بنموذج لغوي |
| 006 | مجالات تشغيلية أصلية وتصنيف REQUIRED_UNVERIFIED حتى الترخيص | حماية الملكية الفكرية والصدق | نسخ نصوص المواصفة |
| 007 | المشروع في مجلد `iso-platform/` على فرع مستقل داخل المستودع الحالي | المستودع الوحيد المتاح للجلسة؛ لا يمس المشاريع الأخرى | — (انظر D-09) |
| 008 | محرر نصي منظم (## / جداول بـ |) بدلاً من محرر WYSIWYG | سريع وآمن ومتوافق مع المقارنة السطرية | مكتبة محرر غني (لاحقاً) |

## افتراضات تشغيلية (اتُّخذت دون الرجوع للمؤسس — قابلة للتغيير)
- اللغة العربية افتراضية والإنجليزية في البيانات والحزم (واجهة EN لاحقاً).
- الاعتماد يتطلب شخصاً غير المُعدّ دائماً (حتى في المنشآت الصغيرة).
- إضافة عضو تنشئ كلمة مرور مؤقتة تظهر مرة واحدة إلى حين اعتماد مزود بريد.
- مدة الجلسة 12 ساعة.
