# PRODUCT_PRD — المتطلبات وقصص المستخدم ومعايير القبول

## الشرائح
منشآت صغيرة ومتوسطة في السعودية والخليج (مطاعم وسلاسل، مصانع، مقاولون، شركات تقنية، خدمات مهنية، تعليم وتدريب)، ثم المؤسسات الكبيرة متعددة المواقع (IMS).

## المنتجات الخمسة وحالتها
| المنتج | المحتوى | الحالة |
|---|---|---|
| A. Discover & Diagnose | تسجيل، ملف منشأة ومواقع، مقابلة تكيفية، كشف تعارضات، حقائق بمصدرها | **منفّذ ومختبر** (عدا: تحليل مستندات العميل المرفوعة، عرض السعر) |
| B. Design & Build | Blueprint، انطباق 17 مجالاً، مخاطر، خطة وثائق، اعتماد النطاق، توليد وثائق، تحرير، مقارنة، اعتماد، DOCX | **منفّذ ومختبر** (عدا: PDF، ZIP، مصفوفة التتبع للمتطلبات المرخصة) |
| C. Implement & Operate | سجلات رقمية، موردون، تدريب، شكاوى، NC/CAPA، أهداف، تغيير | P3 — لم يبدأ |
| D. Audit & Improve | برامج تدقيق، أدلة، تقارير، CAPA، مراجعة إدارة | P3 — لم يبدأ |
| E. Marketplace | باقات، اشتراكات، مراجعة خبراء، فوترة | P4 — يتطلب قرارات المؤسس |

## قصص المستخدم المنفذة (مع اختباراتها)
| القصة | معيار القبول | الدليل |
|---|---|---|
| كمالك، أسجل وأنشئ منشأتي ومواقعها | مقر رئيسي تلقائي، مواقع إضافية، سجل أحداث | E2E خطوات 1–3، `auth-rbac.test.ts` |
| كمالك، أضيف فريقي بأدوار | كلمة مرور مؤقتة تظهر مرة واحدة وتُفرض إعادة تعيينها | E2E خطوات 4، 10 |
| كمساهم، أجيب مقابلة تتكيف مع نشاطي | أسئلة قطاعية، تفرع شرطي، حفظ تلقائي، تحرير لاحق | `engine.test.ts`، E2E 5 |
| كمستخدم، أرى التعارضات قبل المتابعة | تعارض حرج يمنع توليد الهيكل | `flow.test.ts`، E2E 5 |
| كمدير جودة، أولّد هيكل النظام | عمليات/انطباق/مخاطر/وثائق مختلفة فعلاً لكل قطاع | `engine.test.ts` (6 قطاعات) |
| كمالك، أعتمد النطاق قبل التوليد الشامل | لا توليد وثائق قبل الاعتماد؛ لا [MISSING] في النطاق | `flow.test.ts`، E2E 7 |
| كفريق، نحرر ونراجع ونعتمد الوثائق | DRAFT→IN_REVIEW→APPROVED→EFFECTIVE→SUPERSEDED، فصل المهام، لا اعتماد مع بيانات ناقصة | `flow.test.ts`، E2E 9–12 |
| كمستخدم، أنزّل الوثيقة Word قابلة للتحرير | RTL، رمز، ترويسة، ترقيم صفحات، سجل إصدارات | `flow.test.ts`، E2E 11، تصيير LibreOffice |

## الحدود (ما لا تفعله المنصة)
لا تمنح شهادات؛ لا تدّعي تغطية كاملة لمتطلبات ISO دون ترخيص ومراجعة خبير؛ لا تختلق توقيعاً أو تاريخاً أو سجلاً؛ لا تقدّم المشورة القانونية التنظيمية دون مصدر وتاريخ تحقق.

## معايير قبول ISO 9001 الأول (الميثاق §18) — الحالة
| المعيار | الحالة |
|---|---|
| تسجيل، مؤسسة، مواقع | ✅ |
| تشخيص أولي ومقابلة تكيفية | ✅ (بدون تحليل مستندات مرفوعة) |
| تحديد نطاق QMS ومراجعة خريطة العمليات | ✅ |
| شراء باقة تجريبياً | ⏳ P4 — بانتظار قرار مزود الدفع |
| وثائق مخصصة قابلة للتحرير والتصدير واعتماد الإصدارات | ✅ DOCX — ⏳ PDF/ZIP |
| سجلات تشغيل حقيقية، أدلة، تدقيق داخلي، CAPA، لوحة أداء | ⏳ P3 |
| دون تسرب بيانات أو اختلاق أدلة | ✅ لما بُني (RLS + اختبارات عزل + بوابات منع الاختلاق) |
