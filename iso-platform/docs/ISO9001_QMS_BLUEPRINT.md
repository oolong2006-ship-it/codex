# ISO9001_QMS_BLUEPRINT — المجالات التشغيلية ونموذج الانطباق والتتبع

> هذه مجالات تصميم تشغيلية أصلية وليست إعادة إنتاج لنص ISO 9001. الربط بمعرّفات المتطلبات يتم فقط عبر ترخيص نشط ومراجعة خبير.

## المجالات الـ17 (المصدر: `src/server/packs/core.ts`)
D01 السياق · D02 الأطراف المعنية والمتطلبات · D03 النطاق · D04 القيادة والسياسة والأدوار · D05 المخاطر والفرص والأهداف والتغيير · D06 الموارد وموارد القياس · D07 المعرفة والكفاءة والتواصل والمعلومات الموثقة · D08 تخطيط العمليات وضبطها · D09 متطلبات العملاء والعقود · D10 التصميم والتطوير · D11 الموردون والمقدَّم خارجياً · D12 الإنتاج/الخدمة والتتبع · D13 الإفراج والمخرجات غير المطابقة · D14 الأداء والرضا والتحليل · D15 التدقيق الداخلي · D16 مراجعة الإدارة · D17 عدم المطابقة والتصحيح والتحسين.

## قواعد الانطباق (rules:v1)
- كل المجالات منطبقة افتراضياً.
- D10 غير منطبق فقط إذا أجاب العميل بـ«لا» على التصميم **وقدّم مسوغاً** (سؤال حرج مشروط)، ولا يُسمح باستبعاده لقطاعات تفرضه (البرمجيات). المسوغ يُنقل حرفياً إلى بيان النطاق.
- عملية ضبط أجهزة القياس (SUP-05) ووثيقتها تُدرج فقط عند استخدام أجهزة قياس تعتمد عليها قرارات القبول.
- التتبع (MF-07) عند اشتراطه.

## تصنيف الوثائق (الميثاق §5)
| التصنيف | المعنى | أمثلة |
|---|---|---|
| REQUIRED_VERIFIED | ملزم ومتحقق منه بمرجع مرخّص ومراجعة خبير | — (لا شيء حالياً) |
| REQUIRED_UNVERIFIED | ممارسة مستقرة في إصدارات 9001؛ بانتظار التأكيد مقابل نص 2026 | النطاق، السياسة، الأهداف |
| SUGGESTED | وسيلة تطبيق مقترحة | الإجراءات، تعليمات العمل، خريطة العمليات، RACI، سجل المخاطر، النماذج |
| OPTIONAL | مفيد وغير إلزامي | دليل الجودة |

## سلسلة الـBlueprint
نشاط المنشأة (answers) → العمليات (processes + مسوغ) → المخاطر (فرضيات INFERRED) → الانطباق (17 مجالاً) → خطة الوثائق (مصنفة) → الوثائق المضبوطة (إصدارات) → [P3] السجلات والأدلة والمسؤولون والمؤشرات → التدقيق والتحسين.

## بوابات منع الاختلاق
- لا توليد هيكل مع حقائق حرجة ناقصة أو متعارضة.
- لا توليد وثائق قبل اعتماد العميل للنطاق.
- القيم التي يقررها العميل (مستهدفات، أسماء شاغلين، توجهات الإدارة) تظهر كـ `[MISSING: …]` وتمنع الاعتماد حتى تُستكمل.
- السياسة لا تحمل توقيعاً أو تاريخ اعتماد مسبقاً؛ النماذج الفارغة تُعلَن أنها ليست دليلاً.
- المخاطر فرضيات حتى تأكيدها؛ الجهات التنظيمية «تحتاج مصدراً وتاريخ تحقق».
