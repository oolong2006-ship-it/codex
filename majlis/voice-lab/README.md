# مختبر الصوت (voice-lab)

أداة تقارن نماذج تفريغ الكلام (ASR) وتوليد الصوت (TTS) والنموذج اللغوي (LLM) **بالأرقام الفعلية لكل لهجة على حدة**، وتكتب النتيجة في [`REPORT.md`](REPORT.md).

**سياسة البيانات (معتمدة):** النماذج كلها مستضافة ذاتياً داخل المملكة. كل مزود في `lab.yaml` يجب أن يعلن موقعه `local` أو `in-kingdom`، وأي قيمة غيرها تُرفض قبل إرسال أي ملف صوتي. المفاتيح لا تُكتب في الإعدادات؛ يُشار إليها باسم متغير بيئة (`api_key_env`).

## التثبيت

```bash
cd majlis/voice-lab
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"                   # الأدوات + الاختبارات
pip install -e ".[faster-whisper]"        # اختياري: حسب النماذج المحلية المستخدمة
cp lab.example.yaml lab.yaml              # ثم فعّل النماذج المستضافة لديكم
```

## سير العمل

| الخطوة            | الأمر                                                                                      | الناتج                                 |
| ----------------- | ------------------------------------------------------------------------------------------ | -------------------------------------- |
| 1. إدخال البيانات | `python -m majlis_voice_lab import --dialect najdi --refs refs.csv --audio-dir ./incoming` | `datasets/najdi/`                      |
| 2. الفحص          | `python -m majlis_voice_lab validate` و `stats`                                            | المشاكل وعدد العينات والدقائق لكل لهجة |
| 3. قياس ASR       | `python -m majlis_voice_lab asr`                                                           | `output/asr_results.json`              |
| 4. توليد الجمل    | `python -m majlis_voice_lab tts`                                                           | `output/tts/<provider>/*.wav`          |
| 5. صفحة الاستماع  | `python -m majlis_voice_lab listening-page`                                                | `output/listening/`                    |
| 6. جمع التقييمات  | `python -m majlis_voice_lab mos --ratings ./ratings`                                       | `output/tts_results.json`              |
| 7. قياس الزمن     | `python -m majlis_voice_lab latency`                                                       | `output/latency_results.json`          |
| 8. التقرير        | `python -m majlis_voice_lab report`                                                        | `REPORT.md`                            |

### 1. إدخال البيانات

ملف `refs.csv` (UTF-8) بالأعمدة: `audio,reference` وأعمدة اختيارية `id,speaker,gender`.

- يُفحص الملف كاملاً قبل النسخ: ملف صوت مفقود، أو مرجع فارغ، أو معرّف مكرر يوقف الإدخال كله دون أن يُنسخ شيء.
- اللهجات: `najdi`, `hijazi`, `southern`, `eastern`, `northern`, `msa_simple`.
- ملفات الصوت لا تُرفع إلى git؛ تبقى في تخزين داخل المملكة.

**حجم العينة:** التقرير يعلّم أي لهجة فيها أقل من 200 جملة بأنها «عينة صغيرة»، ولا يمنحها ✅ حتى لو كان الرقم تحت 8٪. والأفضل تنوع المتحدثين (جنس، عمر، مدينة) أكثر من كثرة الجمل لمتحدث واحد.

### 4–6. الاستماع الأعمى (MOS)

- الجمل العشرون في `sentences.yaml` مكتوبة كما تُنطق: أرقام وعملة باللهجة، وخلط عربي-إنجليزي، وأسماء علامات تجارية، وسؤال حساس، وإفصاح.
- مجلد `output/listening/` هو ما يُرسل للمقيّمين. أسماء ملفاته عشوائية ولا يحتوي اسم أي نموذج. مفتاح الربط `output/tts/key.json` يبقى عند الفريق ولا يُرسل.
- المقيّم يفتح `index.html` (يعمل على الجوال وبدون إنترنت)، ويقيّم كل صوت من 1 إلى 5، ويحدد هل اللهجة صحيحة، ثم يقارن أزواجاً (أ/ب)، وفي الختام يحمّل ملف تقييم JSON.
- ضعوا ملفات التقييم في مجلد واحد ثم شغّلوا `mos`.

### 7. قياس الزمن

يقيس: ASR على الجملة كاملة، ثم LLM حتى أول جملة مكتملة، ثم TTS حتى أول مقطع صوت. يُستبعد أول دور لأنه يشمل تحميل النموذج. شبكة المتصفح تُقاس لاحقاً في `voice-gateway` (المرحلة 3).

## المحوّلات المتاحة (adapters)

| النوع | المحوّل             | الاستخدام                                                         |
| ----- | ------------------- | ----------------------------------------------------------------- |
| ASR   | `faster-whisper`    | Whisper محلياً عبر CTranslate2                                    |
| ASR   | `transformers`      | أي نقطة حفظ (checkpoint) لنموذج ASR من Hugging Face محفوظة محلياً |
| ASR   | `openai-compatible` | خادم داخلي يقدّم `/v1/audio/transcriptions`                       |
| TTS   | `chatterbox`        | Chatterbox متعدد اللغات محلياً، مع عينة صوت مرجعية لكل جنس        |
| TTS   | `command`           | أي أداة سطر أوامر (مثل Piper)                                     |
| TTS   | `openai-compatible` | خادم داخلي يقدّم `/v1/audio/speech`                               |
| LLM   | `openai-compatible` | vLLM أو TGI أو llama.cpp على خادم داخلي                           |
| الكل  | `mock`              | للاختبارات فقط، والتقرير يحذّر صراحة إذا استُخدم                  |

## مرشحون للتجربة

**الترخيص:** يجب التحقق منه في بطاقة كل نموذج قبل الإنتاج. التقرير يعلّم التراخيص غير التجارية بـ 🚫 ويستبعدها من التوصية.

- **ASR:** Whisper large-v3 و large-v3-turbo (MIT). أي نموذج مضبوط (fine-tuned) على بيانات سعودية يُضاف بمحوّل `transformers`.
- **TTS:** Chatterbox Multilingual (يدعم العربية). أصوات Piper العربية. نماذج مثل MMS-TTS و XTTS-v2 تراخيصها غير تجارية، فتصلح للمقارنة المرجعية فقط.
- **LLM:** نماذج عربية مفتوحة الأوزان مثل ALLaM و Jais و Qwen، تُخدم عبر vLLM داخل المملكة.

**توقع، لا قياس:** النماذج العامة غير المضبوطة يُتوقع أن تكون بعيدة عن WER أقل من 8٪ في اللهجات، خصوصاً الجنوبية والشمالية. الأرجح أن الوصول للمعيار يحتاج ضبطاً على بيانات سعودية، وهذا ما سيحسمه التقرير بالأرقام.
