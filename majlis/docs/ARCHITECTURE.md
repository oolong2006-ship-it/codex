# معمارية «مجلس»

> وثيقة حيّة تُحدَّث مع كل مرحلة. القرارات المعلّمة بـ ⏳ ما زالت تنتظر موافقة.

## 1. الصورة العامة

```
 المشارك (متصفح / واتساب / هاتف لاحقاً)              العميل (لوحة التحكم)
        │  WebSocket (صوت)    │ webhook                       │ HTTPS
        ▼                     ▼                               ▼
 ┌──────────────────┐   ┌──────────────┐              ┌──────────────┐
 │  voice-gateway   │   │   worker     │◄── Redis ───►│   web        │
 │  ASR→LLM→TTS     │   │  (BullMQ)    │   (queue)    │  Next.js RTL │
 │  VAD + barge-in  │   │  تفريغ نهائي │              │  لوحة + مشارك │
 │  قياس الزمن      │   │  تحليل/Personas│             └──────┬───────┘
 └───────┬──────────┘   │  حذف آلي      │                     │
         │              └──────┬───────┘                     │
         │      packages: interviewer · dialect · providers · i18n · db
         ▼                     ▼                             ▼
   ┌───────────────────────────────────────────────────────────────┐
   │ PostgreSQL + pgvector      تخزين S3-متوافق (تسجيلات مشفّرة)     │
   │            كلها داخل DATA_REGION (داخل المملكة)                 │
   └───────────────────────────────────────────────────────────────┘
```

## 2. القرارات ومبرراتها

| القرار            | الاختيار                                   | المبرر                                                                                                                            |
| ----------------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| مكان المشروع      | مجلد `majlis/` داخل المستودع الحالي        | معتمد. معزول تماماً عن MASAR 34 و alnadeg، بمدير حزم و CI خاصين.                                                                  |
| Monorepo          | pnpm workspaces + Turborepo                | تثبيت سريع، عزل صارم للاعتماديات، وتخزين مؤقت للمهام في CI.                                                                       |
| لغة voice-gateway | Node.js + TypeScript (Fastify + WebSocket) | معتمد. يشارك حزم `interviewer` و `dialect` مباشرة بلا قفزة شبكة داخل كل دور، وهذا مهم لميزانية 800ms.                             |
| مختبر الصوت       | Python                                     | أنسب أدوات القياس (jiwer لـ WER/CER) ومعالجة الصوت. لا يدخل مسار الإنتاج.                                                         |
| قاعدة البيانات    | PostgreSQL 16 + pgvector                   | للبحث الدلالي في «ذاكرة المستهلك» ضمن نفس قاعدة البيانات.                                                                         |
| ORM               | Drizzle                                    | معتمد. يدعم نوع `vector` أصلياً، ومخطط TypeScript صريح بلا مولّد كود ثقيل.                                                        |
| الواجهة           | Next.js 15 (App Router) + Tailwind 4       | مسار `/[locale]` بـ `ar` افتراضياً و `dir` يُضبط من اللغة. خصائص CSS منطقية (`ps-`, `ms-`, `border-s`) لدعم RTL و LTR بنفس الكود. |
| الخط              | IBM Plex Sans Arabic عبر `@fontsource`     | مستضاف ذاتياً، فلا طلبات لخوادم خارجية أثناء البناء أو التصفح.                                                                    |
| الترجمة           | حزمة `@majlis/i18n` (ملفات JSON)           | العربية هي المصدر، ومفاتيحها مُنمَّطة في TypeScript. اختبار يضمن تطابق مفاتيح `ar` و `en`. لا نصوص عربية داخل المكونات.           |
| الطابور           | BullMQ على Redis                           | تكرار المحاولة، المهام المجدولة (cron للحذف الآلي)، والأولويات.                                                                   |
| التخزين           | S3-متوافق (MinIO محلياً)                   | يتيح أي مزود داخل المملكة يدعم واجهة S3، مع تشفير من جهة الخادم.                                                                  |

## 3. طبقة المزودين

كل مزود خلف واجهة موحّدة في `packages/providers/src/types.ts`:

| النوع          | الواجهة                                                    | المتغير              |
| -------------- | ---------------------------------------------------------- | -------------------- |
| تفريغ الكلام   | `AsrProvider` (دفعي + متدفق)                               | `ASR_PROVIDER`       |
| توليد الصوت    | `TtsProvider` (متدفق، يُلغى بـ `AbortSignal` عند المقاطعة) | `TTS_PROVIDER`       |
| النموذج اللغوي | `LlmProvider` (متدفق)                                      | `LLM_PROVIDER`       |
| الهاتف         | `TelephonyProvider` (واجهة فقط في MVP)                     | `TELEPHONY_PROVIDER` |
| واتساب         | `WhatsAppProvider`                                         | `WHATSAPP_PROVIDER`  |

- `createProviders(env)` يختار المزود بالاسم ويرفض الأسماء المجهولة برسالة واضحة.
- المزود الوحيد المسجّل حالياً هو `mock`، وهو حتمي ولا يتصل بالشبكة، ويُستخدم في الاختبارات و CI.
- لا يُكتب اسم مزود في منطق العمل. المزودون الحقيقيون يُضافون في `registry.ts` بعد الموافقة.
- واجهات الهاتف وواتساب تتعامل مع `participantRef` معتم، ولا يمر رقم الجوال عبر منطق العمل.

## 4. الخصوصية و PDPL

- لا توجد منطقة سحابية مكتوبة في الكود. كل شيء يُقرأ من `DATA_REGION`.
- الكاميرا ممنوعة على مستوى المتصفح عبر `Permissions-Policy: camera=()`، والميكروفون مسموح لنفس الأصل فقط.
- بيانات المشارك التي تصل للعميل محصورة في: اللهجة، الجنس، المدينة، الفئة العمرية. سيُضاف اختبار امتثال يفحص كل API يصل للعميل.
- سياسة الاحتفاظ: الافتراضي من `RETENTION_DEFAULT_DAYS`، ويقابلها في الطابور مهمة `retention-sweep` المجدولة.

### ⏳ قرار معلّق: معالجة الصوت لدى مزودين خارج المملكة

أغلب مزودي ASR/TTS/LLM التجاريين يعالجون البيانات خارج المملكة. إرسال صوت المشارك إليهم نقل للبيانات عبر الحدود، حتى لو كان التخزين داخل `DATA_REGION`. الخيارات:

1. نماذج مستضافة ذاتياً داخل المملكة، بتكلفة تشغيلية أعلى.
2. مسار قانوني للنقل عبر الحدود، مع توثيق ومراجعة قانونية.

يحدد هذا القرار من يدخل مقارنة مختبر الصوت في المرحلة 1.

## 5. قرارات معلّقة أخرى ⏳

- المزودون المرشحون لمختبر الصوت (ASR / TTS / LLM).
- مزود السحابة داخل المملكة وبنية النشر (حاويات أو خدمة مُدارة).
- مزود واتساب Business API.
