# معمارية «مجلس»

> وثيقة حيّة تُحدَّث مع كل مرحلة. القرارات المعلّمة بـ ⏳ ما زالت تنتظر موافقة.

## 1. الصورة العامة

```
 المشارك (متصفح / واتساب / هاتف لاحقاً)              العميل (لوحة التحكم)
        │  WebSocket (صوت)    │ webhook                       │ HTTPS
        ▼                     ▼                               ▼
 ┌──────────────────┐   ┌──────────────┐              ┌──────────────┐
 │  voice-gateway   │   │   worker     │◄── jobs ────►│   web        │
 │  ASR→LLM→TTS     │   │ (PostgreSQL) │  (جدول)      │  Next.js RTL │
 │  VAD + barge-in  │   │  تفريغ نهائي │              │  لوحة + مشارك │
 │  قياس الزمن      │   │  تحليل/Personas│             └──────┬───────┘
 └───────┬──────────┘   │  حذف آلي      │                     │
         │              └──────┬───────┘                     │
         │   packages: interviewer · dialect · analysis · providers · i18n · db
         ▼                     ▼                             ▼
   ┌───────────────────────────────────────────────────────────────┐
   │ PostgreSQL + pgvector      تخزين S3-متوافق (تسجيلات مشفّرة)     │
   │            كلها داخل DATA_REGION (داخل المملكة)                 │
   └───────────────────────────────────────────────────────────────┘
```

## 3. طبقة المزودين

كل مزود خلف واجهة موحّدة في `packages/providers/src/types.ts`:

| النوع          | الواجهة                                                    | المتغير              |
| -------------- | ---------------------------------------------------------- | -------------------- |
| تفريغ الكلام   | `AsrProvider` (دفعي + متدفق)                               | `ASR_PROVIDER`       |
| توليد الصوت    | `TtsProvider` (متدفق، يُلغى بـ `AbortSignal` عند المقاطعة) | `TTS_PROVIDER`       |
| النموذج اللغوي | `LlmProvider` (متدفق)                                      | `LLM_PROVIDER`       |
| الهاتف         | `TelephonyProvider` (واجهة فقط في MVP)                     | `TELEPHONY_PROVIDER` |
| واتساب         | `WhatsAppProvider`                                         | `WHATSAPP_PROVIDER`  |

- `createProviders(env)` يختار المزود بالاسم ويرفض الأسماء المجهولة برسالة واضحة.
- المحوّلات المسجّلة:
  - `mock`: حتمي ولا يتصل بالشبكة، ويُستخدم في الاختبارات و CI.
  - `openai-compatible`: لخوادم نستضيفها داخل المملكة، مثل vLLM و faster-whisper-server و llama.cpp.
- كل محوّل غير `mock` يجب أن يعلن `<KIND>_LOCATION=in-kingdom|local`، وإلا ترفض البوابة التشغيل.
- لا يُكتب اسم مزود في منطق العمل.
- واجهات الهاتف وواتساب تتعامل مع `participantRef` معتم، ولا يمر رقم الجوال عبر منطق العمل.

## 4. الخصوصية و PDPL

- لا توجد منطقة سحابية مكتوبة في الكود. كل شيء يُقرأ من `DATA_REGION`.
- الكاميرا ممنوعة على مستوى المتصفح عبر `Permissions-Policy: camera=()`، والميكروفون مسموح لنفس الأصل فقط.
- **ما يصل للعميل:**
  - من بيانات المشارك: اللهجة، الجنس، المدينة، الفئة العمرية فقط. جدول `participants` لا يحتوي اسماً ولا رقماً ولا بريداً أصلاً.
  - كل نص يصل للعميل يمر عبر `redactPII`، التي تحذف أرقام الجوال والبريد والهويات والآيبان. الأسماء لا يمكن كشفها آلياً بموثوقية، فهي غير مغطاة.
  - كل دوال العرض للعميل (`client-views.ts`) مقيدة بمنظمته.
  - اختبار امتثال يفحص المفاتيح والقيم في كل ما يُعاد للعميل.
- سياسة الاحتفاظ: الافتراضي من `RETENTION_DEFAULT_DAYS`، ويقابلها في الطابور مهمة `retention-sweep` المجدولة.

### ✅ معالجة الصوت: نماذج مستضافة ذاتياً داخل المملكة فقط

معتمد. لا يُرسل صوت المشارك ولا نص المقابلة إلى أي مزود خارج المملكة. النتائج العملية:

- كل محوّلات الإنتاج لنماذج نستضيفها: محلية، أو خوادم داخلية متوافقة مع واجهة OpenAI (vLLM، faster-whisper-server وغيرها).
- مختبر الصوت يرفض أي مزود لا يعلن `location: local | in-kingdom`.
- لا حاجة لحسابات مزودين مدفوعين. التكلفة تنتقل إلى البنية: خوادم GPU داخل المملكة، وهذا يدخل في قرار بنية النشر.
- الترخيص صار شرطاً: النماذج بتراخيص غير تجارية تُستبعد من الإنتاج، والتقرير يعلّمها.

## 5. قرارات معلّقة أخرى ⏳

- النماذج النهائية لـ ASR / TTS / LLM: تُحسم بأرقام `voice-lab/REPORT.md` بعد تشغيله على البيانات الحقيقية.
- مزود السحابة داخل المملكة وبنية النشر، بما فيها خوادم GPU للنماذج.
- مزود واتساب Business API.

## 6. المحاور: من يقرر ماذا

```
كلام المشارك ─► تصحيح التفريغ ─► تصنيف (موافقة / رفض إجابة / «إنت إنسان؟» / عمق الإجابة)
                                     │
                       آلة الحالات (حتمية، قابلة للاختبار)
                 تقرر الفعل: سؤال، متابعة، اعتذار، إفصاح صادق، ختام
                                     │  نص مقترح من ملف العبارات
                                     ▼
              LLM (اختياري): يعيد الصياغة فقط لـ «سؤال» و «متابعة»
                                     │
                        الحواجز: ادعاء إنسانية، سؤال موجّه، حكم،
                        مصطلحات أكاديمية، لهجة مصطنعة، طول، تعدد أسئلة
                     ✗ مخالفة ◄─┴─► ✓ مقبول
                  (يُستخدم النص المقترح)     │
                                     ▼
                    ar_sa_normalizer ─► نص الصوت (TTS)
```

- **الإفصاح والموافقة والإجابة الصادقة عن الهوية** نصوص ثابتة لا يعيد النموذج اللغوي صياغتها أبداً. نص الإفصاح وبصمته (SHA-256) ورقم نسخته تُحفظ في سجل الموافقة.
- **لا موافقة صريحة = لا مقابلة:** الإجابة الغامضة تُستوضح مرتين، وبعدها تنتهي الجلسة بلطف.
- **المتابعة:** للإجابات القصيرة أو العامة، بحد أقصى سؤالين لكل محور، ولا متابعة أبداً على سؤال حساس أو سؤال رفض المشارك إجابته.
- **عدم التكرار:** السؤال الذي غطّته إجابات سابقة (حسب `coverKeywords`) يُتخطى، ويُسجَّل ذلك كحدث.
- **اللهجة:** تُكتشف من أول إجابتين فيهما معلومة، فالردود من كلمة واحدة لا تُحسب. بعدها تدخل ردود الإنصات الخاصة باللهجة تدريجياً. إذا لم يكن الدليل واضحاً يبقى المحاور على اللهجة البيضاء.
- **صيغ المخاطبة:** العبارات بصيغة المذكر أو المؤنث حسب جنس المشارك، وبصيغة محايدة إذا كان غير معروف. وصف المحاور («مساعد ذكي» / «مساعدة ذكية») يتبع جنس صوته.

## 7. البوابة الصوتية (voice-gateway)

```
المتصفح (AudioWorklet، 16kHz، إطارات 20ms، إلغاء الصدى)
   │ WebSocket: صوت ثنائي + رسائل JSON  (packages/voice-client/src/protocol.ts)
   ▼
VAD (طاقة الصوت) ─► ASR متدفق ─► المحاور ─► TTS جملة جملة ─► المتصفح
   │                                              ▲
   └─ كلام أثناء رد مسموع  ──► إلغاء فوري (barge-in)
   └─ كلام قبل أن يُسمع الرد ─► سحب الرد، استرجاع الحالة، دمج الكلامين
```

- **عدم المقاطعة:**
  - المحاور لا يرد قبل صمت `VAD_END_SILENCE_MS`. الافتراضي 500ms، فالوقفة القصيرة وسط الجملة لا تُعتبر نهاية كلام.
  - إذا عاد المشارك للكلام قبل أن يُسمع الرد، يُسحب الرد وتُستعاد حالة المقابلة (`snapshot/restore`)، ويُعامَل الكلامان كإجابة واحدة.
- **المقاطعة (barge-in):**
  - أي كلام يُكتشف والرد مسموع (يُبث، أو ما زال يُشغَّل في المتصفح) يوقفه فوراً، ويوقف المتصفح التشغيل حين يصله الإلغاء.
  - الكلام أقصر من `VAD_MIN_SPEECH_MS` (نقرات وأصوات قصيرة) لا يُحسب.
- **قياس الزمن لكل دور:** من آخر إطار فيه صوت للمشارك حتى أول مقطع رد، مفصلاً: انتظار نهاية الكلام، ثم ASR، ثم المحاور، ثم أول صوت. يُحسب أيضاً الزمن المحسوس، أي حتى يبلغ المتصفح عن بدء التشغيل. الملخص p50/p90 يُحفظ مع الجلسة (`latencyStats`).
- **الأمان:**
  - معرّف الجلسة عشوائي غير قابل للتخمين.
  - البث مقيد بالأصول المسموحة.
  - الجلسة تُفتح مرة واحدة فقط.
  - واجهة إنشاء الجلسات داخلية بمفتاح مشترك، ومخفية إذا لم يُضبط المفتاح.
  - حجم الإطار محدود.
- **لا تسجيل للصوت بعد:** حفظ المقاطع (`Turn.audioRef`) يأتي مع التخزين المشفّر وسياسة الاحتفاظ.

### ميزانية الزمن (800ms عند p90) — قيد بنيوي يجب أن يُعرف مبكراً

| الجزء                                                   | الزمن                           |
| ------------------------------------------------------- | ------------------------------- |
| انتظار الصمت لتأكيد نهاية الكلام (`VAD_END_SILENCE_MS`) | 500ms ثابتة افتراضياً           |
| ASR على المقطع كاملاً + المحاور + أول مقطع TTS          | يجب أن يكون أقل من 300ms مجتمعة |

- إعادة صياغة الأسئلة بالنموذج اللغوي معطّلة افتراضياً (`INTERVIEWER_LLM_REPHRASE=false`)، لأنها تضيف زمن التوليد كاملاً.
- تقليل الصمت إلى 300ms يوسّع الميزانية، لكنه يرفع خطر مقاطعة من يتوقف ليفكر.
- البديل الأفضل كاشف نهاية كلام دلالي (semantic endpointing)، وهو قرار يُتخذ بعد قياس الأرقام الحقيقية على خوادمنا.

## 8. لوحة العميل وتجربة المشارك

```
العميل: هدف بجملة ─► قالب أو LLM (يفلتره نفس حواجز المحاور) ─► دليل قابل للتعديل (نسخ مرقّمة)
        ─► الشريحة وصوت المحاور ─► فتح الاستقبال ─► رابط + QR + واتساب

المشارك: ترحيب ─► عنك + أسئلة الفرز ─► الإفصاح بنصه + الموافقة + اختيار الصوت ─► «ابدأ»
        ─► startInterview (معاملة واحدة: مشارك + جلسة + سجل موافقة بنص الإفصاح وبصمته)
        ─► البوابة: ترفض أي جلسة بلا سجل موافقة، وتُفتح الجلسة مرة واحدة فقط
        ─► مقابلة صوتية (موجة صوت هادئة، بلا وجه) أو كتابة في أي لحظة ─► شكر وحافز
```

- **الإفصاح:** نص الإفصاح المعروض قبل الموافقة يولّده المحرك نفسه، فهو حرفياً ما سيقوله المحاور، ويُحفظ هو وبصمته في سجل الموافقة. الموافقة الشفهية داخل المقابلة تُسجَّل كسجل ثانٍ.
- **الدليل:** كل حفظ يُنشئ نسخة جديدة، والجلسة تحفظ نسخة مجمّدة من الدليل الذي استُخدم، فتعديل لاحق لا يغيّر مقابلة سابقة. الصياغة التي سترفضها حواجز المحاور تُعرض كملاحظة للمؤلف.
- **صيغ المخاطبة:** لكل سؤال صيغة مذكر أو محايدة، وصيغة مؤنث اختيارية.
- **الدخول:** كلمات المرور بـ scrypt. كعكة جلسة عشوائية `httpOnly` و `SameSite=Lax`، ولا يُحفظ في القاعدة إلا SHA-256 لها.
- **الحزم الداخلية** (`db` و `interviewer` و `dialect` و `providers`) تُحمَّل في خادم Next كما هي دون تجميع، لأنها تقرأ ملفات بيانات بجانبها.

## 9. التحليل وذاكرة المستهلك

```
مقابلة مكتملة ─► مهمة analyze-session ─► العامل:
   1. متجهات لإجابات المشارك (من النص بعد حذف البيانات الشخصية) ─► turns.embedding (HNSW)
   2. محاور الدراسة = أقسام الدليل: مشاعر، عدد، اقتباسات متنوعة، تفصيل حسب الشرائح ─► insights
   3. ملخص بنموذج لغوي (اختياري، من الاقتباسات فقط)
   ─► مهمة update-personas (مدموجة لكل منظمة) ─► Personas بنسخ تزيد عند تغيّر الذاكرة

«اسأل ذاكرتك»: سؤال ─► فلاتر الفئة من النص (الجنس، العمر، المدينة، اللهجة) ─► بحث دلالي
             مقيّد بالمنظمة والفئة وعتبة تشابه ─► إجابة من الاقتباسات فقط
```

- **المشاعر:** تصنيف مبدئي بقاموس سعودي (`analysis/lexicon`) مع النفي، بما فيه النفي الملتصق بحرف العطف («وما تستاهل»). الواجهة تعرض هذا التحفظ صراحة، والدقة تُقاس على بيانات موسومة.
- **المحاور:** تتبع أقسام الدليل، فهي مفهومة للعميل وقابلة للمقارنة بين المقابلات.
- **الـ Personas:** شريحة لكل قيمة (الجنس، العمر، المدينة، اللهجة، الجنس × العمر). لا تظهر الشريحة إلا بعد عدد كافٍ من المقابلات (`PERSONA_MIN_SESSIONS`، الافتراضي 3). فيها ما تمدحه الشريحة وما تشتكي منه، مع اقتباسات.
- **«اسأل ذاكرتك»:**
  - لا يجيب إلا من الاقتباسات.
  - إجابة النموذج اللغوي تُقبل فقط إذا استشهدت بأرقام اقتباسات موجودة، وإلا يُعرض الملخص المستخرج.
  - إذا لم يتجاوز أي اقتباس عتبة التشابه، يقول إن البيانات لا تكفي.
  - إذا سُئل عن صفة لا نجمعها، مثل الأمومة، يقول ذلك ويستخدم أقرب فئة مسجلة.
