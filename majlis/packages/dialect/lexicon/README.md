# قاموس اللهجات

ملف لكل لهجة، مع ملف مشترك `common.yaml`. كل الملفات **مسودة** تحتاج مراجعة متحدثين أصليين من كل منطقة قبل الإنتاج.

| الحقل                                     | الاستخدام                                                              |
| ----------------------------------------- | ---------------------------------------------------------------------- |
| `markers`                                 | كلمات دالة على اللهجة مع وزنها (1–3)؛ يستخدمها كاشف اللهجة             |
| `vocabulary`                              | المفردة ومعناها بالفصحى                                                |
| `greetings` / `closings` / `backchannels` | عبارات المحاور حسب اللهجة                                              |
| `avoid`                                   | عبارات تبدو مصطنعة أو من لهجة أخرى؛ يفحصها مدقق صحة اللهجة             |
| `brands` (مشترك)                          | نطق العلامات التجارية كما يقولها السعوديون، قبل إرسال النص لمحرك الصوت |
| `asr_corrections` (مشترك)                 | توحيد أخطاء الإملاء الشائعة في التفريغ                                 |

تُطابق الكلمات بعد التطبيع: إزالة التشكيل، وتوحيد الألف، وتحويل ة إلى ه وى إلى ي. لذلك تكفي كتابة الكلمة بشكل واحد.

ملفا الجنوبية والشمالية قليلا العلامات عمداً، لأن التخمين فيهما أسوأ من النقص. يكمّلهما مراجعون من المنطقة.
