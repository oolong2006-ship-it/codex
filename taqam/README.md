# طاقم | Taqam

> منصة سعودية للموارد البشرية والرواتب **مصممة للمنشآت متعددة الفروع**: المطاعم، والتجزئة، والمقاولات، والعيادات، والخدمات اللوجستية.

الفرع هو قلب النظام في طاقم: لكل فرع نطاق جغرافي للحضور، ووردياته، ومديره، ونسبة سعودة خاصة به. والموظف الميداني يستخدم تطبيق خدمة ذاتية من جواله.

---

## ما الذي تحتويه المنصة؟

| الجزء | المسار | الوصف |
|---|---|---|
| 🌐 الموقع التعريفي | `/` | الرئيسية، والمزايا، والحلول لكل قطاع، والأسعار، وطلب عرض تجريبي، وحاسبة نهاية الخدمة المجانية |
| 🖥️ لوحة تحكم الشركة | `/app` | الموظفون، والفروع، والحضور والورديات، والإجازات، والطلبات، والرواتب وحماية الأجور، والسلف، والسعودة، والأداء، والتوظيف، والتقارير، والإعدادات |
| 📱 تطبيق الموظف (PWA) | `/me` | بصمة حضور بالموقع، وإجازات، وقسائم رواتب، وطلبات، وملف شخصي |
| 🛡️ بوابة مالك المنصة | `/admin` | تفعيل حسابات الشركات وإيقافها، والباقات والاشتراكات، وحدود المقاعد، والإيرادات المتكررة، والدخول كمالك المنشأة للدعم، وطلبات العروض، والتعاميم |
| ⚙️ الخادم (API) | `:4100/api` | NestJS + PostgreSQL، و112 مساراً، وتوثيق Swagger على `/api/docs` |
| 🧮 محرك الاحتساب | `packages/core` | نظام العمل السعودي: التأمينات، ونهاية الخدمة (م84/85)، والعمل الإضافي (م107)، والإجازات (م109/117)، وسقف الخصومات (م92)، وملف حماية الأجور، ونطاقات |

## البنية

```
taqam/
├── packages/core/   محرك الاحتساب (TypeScript خالص + 85 اختباراً)
├── apps/api/        الخادم: NestJS 10 + Prisma 5 + PostgreSQL
├── apps/web/        الواجهة: Next.js 15 + React 19 + Tailwind (عربي RTL مع الإنجليزية)
├── docs/            وثيقة المنتج + عقد الـ API + عقد محرك الاحتساب
└── docker-compose.yml
```

## التشغيل

### الخيار 1: Docker (الأسهل)

```bash
cd taqam
docker compose --profile demo up --build   # يشغّل المنصة مع البيانات التجريبية
# أو بدون بيانات تجريبية:
docker compose up --build
```

ثم افتح:
- الموقع ولوحة التحكم: http://localhost:3100
- الخادم وتوثيقه: http://localhost:4100/api/docs

### الخيار 2: تشغيل يدوي للتطوير

يتطلب Node.js 20 أو أحدث، وPostgreSQL 16.

```bash
# 1) محرك الاحتساب
cd taqam/packages/core && npm install && npm run build

# 2) الخادم
cd ../../apps/api
cp .env.example .env          # عدّل DATABASE_URL إن لزم
npm install
npm run db:migrate && npm run db:seed
npm run dev                   # http://localhost:4100/api

# 3) الواجهة (في نافذة أخرى)
cd ../web
npm install
npm run dev                   # http://localhost:3100
```

البيانات التجريبية لشركة «مطاعم ورد الشام»: 4 فروع و40 موظفاً، مع حضور وإجازات و3 مسيرات رواتب سابقة.
كلمة المرور لجميع الحسابات: **`Taqam@2026`**

| البريد | الدور |
|---|---|
| `owner@taqam.demo` | المالك |
| `hr@taqam.demo` | مدير الموارد البشرية |
| `payroll@taqam.demo` | مسؤول الرواتب |
| `manager@taqam.demo` | مدير فرع العليا |
| `employee@taqam.demo` | موظف (يفتح تطبيق الخدمة الذاتية) |
| `admin@taqam.demo` | **مالك المنصة**: بوابة إدارة الشركات المشتركة `/admin` |

## قبل الإطلاق التجاري

البرمجة جاهزة، لكن هذه البنود تتطلب إجراءات منك:

1. **الربط الحكومي المباشر** (التأمينات، ومُدد، وقوى، ومقيم) والبنوك: يحتاج سجلاً تجارياً واتفاقيات واعتماداً كمزوّد خدمة. المنصة تُصدر الآن ملف حماية الأجور (CSV) بصيغة عامة قابلة للتخصيص حسب البنك.
2. **الاستضافة داخل المملكة** والامتثال لنظام حماية البيانات الشخصية (PDPL): يُنصح بمراجعة مختص قانوني.
3. **مراجعة محاسبية** لنسب التأمينات وقواعد الاحتساب، فهي قابلة للتعديل من `packages/core`. حدود نطاقات المعروضة توضيحية، والحدود الفعلية تختلف حسب النشاط وحجم المنشأة.
4. **تغيير الأسرار**: غيّر `JWT_SECRET` و`POSTGRES_PASSWORD`، واضبط `PLATFORM_ADMIN_EMAIL` و`PLATFORM_ADMIN_PASSWORD` لإنشاء حساب مالك المنصة.
5. **استبدال البيانات المؤقتة** في الموقع التعريفي: النطاق `taqam.sa`، والبريد، ورقم الهاتف، والشهادات التوضيحية.
