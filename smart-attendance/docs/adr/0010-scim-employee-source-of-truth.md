# ADR-0010: SCIM ومصدر حقيقة الموظف

- **الحالة:** معتمد — 2026-10-26 (اعتماد المالك الشامل لمقترحات الفريق)
- **التفصيل الملزم:** `docs/product/integration-hub.md` §1 و(ج)

## القرار
- مصدر حقيقة واحد لكل كيان لكل عميل: الحضور والقرارات والجلسات **عندنا دائمًا**؛ الموظف والإجازات **عند نظام HR/SCIM** إن رُبط، وإلا عندنا.
- لا مزامنة ثنائية الاتجاه على الحقل نفسه.
- مفتاح المطابقة: `employee_number` الفريد لكل عميل، مع `external_refs` لكل نظام.
- SCIM لا يمنح أدوار إدارة دون ربط مجموعات صريح (S12).
