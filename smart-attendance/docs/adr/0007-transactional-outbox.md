# ADR-0007: Transactional Outbox وضمانات التسليم

- **الحالة:** معتمد — 2026-10-26 (اعتماد المالك الشامل لمقترحات الفريق)
- **التفصيل الملزم:** `docs/product/integration-hub.md` §3.0

## القرار
- كل حدث تكامل يُكتب في جدول `integration_outbox` **في نفس المعاملة** مع التغيير، ثم ينشره عامل BullMQ.
- التسليم **at-least-once** مع `id` ثابت لإزالة التكرار عند المستقبل؛ الترتيب مضمون **لكل كيان** عبر `entity_version`.
- الـ backfill يُولّد من الحالة الحالية (الجلسات قابلة لإعادة البناء).
- كل مهمة تضبط `app.tenant_id` قبل أي استعلام، وإلا تفشل (security S8).
