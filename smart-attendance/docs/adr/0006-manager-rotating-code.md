# ADR-0006: رمز تحدٍّ دوّار على جوال مدير الفرع

- **الحالة:** معتمد — 2026-10-26 (اعتماد المالك الشامل لمقترحات الفريق) — **التنفيذ بعد الـ Pilot**
- **التفصيل الملزم:** `docs/product/trust-accuracy.md` §7

## القرار
- جوال مدير الفرع المربوط يعرض رمزًا قصير العمر مرتبطًا بالموقع والوقت، يُدخله أو يمسحه الموظف كـ**عامل ثانٍ** في وضعية STRICT أو كمسار لحسم `PENDING` في الحال.
- ليس بديلًا عن الموقع ولا عن ربط الجهاز، ولا يُعد «QR ثابتًا» (الميثاق §2) لأنه دوّار وصادر من جهاز موثق.
- رمز منتهٍ أو لموقع آخر لا يُحتسب (F41).
