# ADR-0011: منع وجهات التكامل خارج المملكة افتراضيًا

- **الحالة:** معتمد — 2026-10-26 (اعتماد المالك الشامل لمقترحات الفريق)
- **التفصيل الملزم:** `docs/product/security-compliance.md` §3.4، و`ksa-requirements.md` P5

## القرار
- وجهات Webhooks وSFTP والموصلات خارج المملكة **ممنوعة افتراضيًا** حتى رأي المستشار النظامي (D-09).
- بعد الرأي: تُسمح لكل عميل بإقرار موثق يحدد الغرض والمستلم وأساس النقل (م 29)، ويُسجل في audit.
- لا معالج فرعي خارجي يستقبل إحداثيات الموظفين (خرائط، crash reporting) — R-L3.
