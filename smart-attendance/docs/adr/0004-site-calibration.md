# ADR-0004: معايرة الفروع ومحاكاة السياسات

- **الحالة:** معتمد — 2026-10-26 (اعتماد المالك الشامل لمقترحات الفريق)
- **التفصيل الملزم:** `docs/product/trust-accuracy.md` §3، و`product-vision.md` K2 وK8

## القرار
- لقطة `site_calibration_snapshot` لكل موقع تُبنى **من البصمات VERIFIED دون أي RISK ومن عدة موظفين فقط** (F35)، بحد أدنى من العينات تحدده السياسة.
- تُنتج **اقتراحات** (مثل `tolerance_m` بسقف، و`known_bssid_hashes`، و`accuracy_p50`)، ولا تُطبَّق إلا باعتماد بشري ينشئ إصدار سياسة جديدًا (F36).
- **Policy Replay:** يعيد تقييم آخر 30 يومًا بالسياسة المقترحة **للقراءة فقط** ويعرض الفرق؛ لا يمس الأحداث أو القرارات التاريخية (F37).
- كل قرار لاحق يحمل `calibration_snapshot_id` (F38).
- قواعد قابلة للتفسير فقط؛ أي نموذج إحصائي يحتاج ADR مستقلًا.
