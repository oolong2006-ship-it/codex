# ADR-0008: مصادقة API العامة

- **الحالة:** معتمد — 2026-10-26 (اعتماد المالك الشامل لمقترحات الفريق)
- **التفصيل الملزم:** `docs/product/integration-hub.md` (أ)، و`security-compliance.md` T1/T2

## القرار
- OAuth2 **client credentials** للأنظمة، ومفاتيح API بنطاقات صريحة (scopes) دون نطاق شامل.
- المفتاح يُخزن **hash فقط**، ويُدوّر بمفتاحين متداخلين، ويُلغى خلال 60 ثانية.
- **لا scope يكتب أحداث بصمة، ولا scope يفعّل جهازًا أو يعتمد تغييره** (F6، S14).
- `tenant_id` يُشتق من سجل الاعتماد لا من الطلب.
- الإحداثيات الخام فقط عبر `evidence:location:read` الممنوح بقرار موثق (PD-07، S20/S21).
