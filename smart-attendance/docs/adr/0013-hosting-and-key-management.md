# ADR-0013: الاستضافة داخل المملكة وإدارة المفاتيح

- **الحالة:** معتمد — 2026-10-26 (اعتماد المالك الشامل لمقترحات الفريق) — **اختيار المزوّد معلق على التحقق (Blocked)**
- **المراجع:** `ksa-requirements.md` §5، و`security-compliance.md` §4

## القرار
- **Supabase مستبعد للإنتاج** (لا منطقة سعودية وفق صفحته الرسمية). التطوير والاختبار على Postgres 16 + PostGIS محلي.
- المرشحان للتحقق: Google Cloud (الدمام) وOracle Cloud (جدة/الرياض)، ثم AWS إن ثبت إطلاق منطقته السعودية رسميًا.
- يجب أن يبقى داخل المملكة: قاعدة البيانات، والنسخ الاحتياطية، والسجلات، وRedis/الطوابير، والأسرار.
- الأسرار وأسرار موصلات العملاء: envelope encryption بمفتاح لكل عميل، مغلّف في KMS المزوّد داخل المنطقة أو Vault ذاتي داخلها (S16/S17).
- الكود لا يعتمد على مزوّد محدد (Postgres قياسي + S3-compatible + KMS عبر adapter).
