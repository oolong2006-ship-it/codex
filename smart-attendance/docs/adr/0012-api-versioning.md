# ADR-0012: إصدارات API وسياسة الإيقاف

- **الحالة:** معتمد — 2026-10-26 (اعتماد المالك الشامل لمقترحات الفريق)
- **التفصيل الملزم:** `docs/product/integration-hub.md` §8.4

## القرار
- مسار رئيسي `/v1`؛ والتغييرات غير الكاسرة تُضاف دون إصدار جديد.
- Webhooks تحمل `api_version` بتاريخ، والعميل يثبت إصداره.
- التغيير الكاسر يتطلب إصدارًا جديدًا وفترة إيقاف معلنة تحددها سياسة المنصة وتُنشر في وثائق API.
- OpenAPI 3.1 يُولّد تلقائيًا من الكود ويُفحص في CI.
