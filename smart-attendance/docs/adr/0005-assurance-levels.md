# ADR-0005: وضعيات الضمان لكل موقع

- **الحالة:** معتمد — 2026-10-26 (اعتماد المالك الشامل لمقترحات الفريق)
- **التفصيل الملزم:** `docs/product/trust-accuracy.md` §6

## القرار
لكل موقع وضعية `STANDARD | HIGH | STRICT` في إصدار السياسة، تغيّر **المدخلات والعتبات** لا المعادلة (specs §B ثابتة). الجدول في trust-accuracy §6 هو القيم الافتراضية المقترحة للسياسة.
- الافتراضي لكل موقع جديد: `STANDARD`.
- العميل التجريبي: `STANDARD` أو `HIGH` فقط في الـ Pilot الأول (PD-16).
- التحقق بالوجه ليس وضعية؛ محجوز لـ `STRICT+BIOMETRIC` مستقبلًا بشروط DPIA وتعديل الميثاق.

## الاختبارات
F34، F42.
