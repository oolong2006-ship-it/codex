# Roadmap

## Next (v0.2)
- WhatsApp approved-template sending for campaigns outside the 24h window; opt-out keyword handling.
- Foodics: verify payload against sandbox, OAuth app install from the Foodics marketplace, branch mapping UI.
- More POS adapters: Marn, Rewaa, Odoo POS.
- Billing (Moyasar / Tap) with plans per branch; trial expiry.
- Phone OTP on enrollment (optional per merchant) to stop fake sign-ups.

## Later
- NFC tap-to-stamp (Apple NFC entitlement, Google Smart Tap).
- AI assistant for merchants: churn prediction, best offer and timing, campaign copy in Saudi dialect.
- Neighbourhood coalition card (several independent cafés on one card).
- Points programs and tiers; multiple programs per merchant.
- Referral / gift a coffee links.
- Postgres row-level security as defence in depth on top of the app-layer tenant scoping.
